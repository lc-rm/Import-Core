# Import Core

応募情報を採用コア取込CSVに変換するWebツール。
複数媒体・複数クライアント・ログイン認証・データ暗号化に対応。

## 主な機能

- **ログイン認証**: パスワード認証 + データ暗号化(AES-GCM 256bit + PBKDF2 100k iterations)
- **マルチユーザー**: ツール上でユーザーを追加・削除
- **クライアント管理**: 追加・編集・削除
- **複数媒体対応**: JOBこあ / Indeed / engage / AirWORK / 求人ボックス / 汎用
- **重複除外**: メール or 電話一致で重複判定、過去5回分の履歴を保持
- **媒体ごとのフォーマット差を吸収**: 文字コード(UTF-8/CP932/Shift-JIS)、電話番号、生年月日、氏名分離をすべて自動処理
- **完全クライアントサイド**: サーバー不要、GitHub Pagesで動作
- **データ暗号化**: 入力された個人情報はパスワードで暗号化されてブラウザに保存

## 使い方

### 初回セットアップ
1. 公開URLにアクセスすると、自動的に **setup.html** に飛ばされる
2. ユーザーIDとパスワードを設定
3. ログイン後、「クライアント・履歴」ページでクライアントを追加
4. 「変換」ページで使用

### 通常の利用
1. ログイン → 「変換」ページ
2. クライアント・媒体を選んでファイルをドラッグ&ドロップ
3. 「新規 N件 / 重複 M件」のサマリーを確認
4. 「新規分のCSVをダウンロード」を押すと:
   - CSVがダウンロード(ステータスは「未対応」固定で出力)
   - 新規分の連絡先キー(メール/電話)が履歴に記録
   - 6回目以降は古い履歴から自動で押し出し

## セキュリティ

### データ保護
- すべてのクライアント情報・取込履歴は **AES-GCM 256bit** で暗号化
- 暗号化キーはログインパスワードから **PBKDF2 (100,000 iterations, SHA-256)** で派生
- パスワードは PBKDF2 + ソルト付き SHA-256 でハッシュ化して保存(平文では保存されない)
- ログイン状態は sessionStorage(ブラウザを閉じると消える、毎回ログイン)

### 注意事項
- ⚠️ **パスワードを忘れると暗号化データは復号できません**
- ⚠️ **クライアントサイド処理のため、HTML/JSコード自体は公開されます**(ロジックは見えるが、データは暗号化されているので個人情報は見えません)
- ⚠️ 同じユーザーIDで別人がログインしてもデータは共有されない作りになっています(暗号化キーがパスワードに依存)。チームで共有する場合は同じID/PWを使う想定です
- 本格的な業務利用では、将来的にサーバー側認証(Vercel/Cloudflare Pagesの環境変数等)に移行を検討してください

## 媒体追加方法

`sources.js` に1オブジェクト追加するだけ。HTMLは触りません。

```javascript
const SOURCES = {
  // ...
  myNewSource: {
    id: 'myNewSource',
    label: '新媒体A',
    mediaName: '新媒体A',
    fileTypes: '.csv,.xlsx',
    encoding: 'utf-8',  // 'utf-8' | 'cp932' | 'auto'
    map: (row, ctx) => {
      const get = n => ctx.get(row, n);
      const [by, bm, bd] = ctx.ymdFromBirth(get('生年月日'));
      return {
        '応募日': ctx.dateOnly(get('応募日列名')),
        '名前':   get('氏名列名'),
        '電話':   ctx.formatPhone(get('電話列名')),
        // ... 他の項目
      };
    }
  }
};
```

`ctx`で利用可能なヘルパー: `norm`, `onlyDigits`, `formatPhone`, `ymdFromBirth`, `dateOnly`, `splitBySlash`, `get`

## 採用コア取込CSV列順(固定)

応募日, 求人番号, 求人名称, 応募職種, 勤務地, 部署, 名前, ふりがな, メール, 電話, 性別, 生年, 月, 日, 媒体名, 人材紹介会社, ステータス, 採用可否, コンタクト日, 1次面接日時, 1次面接結果, 2次面接日時, 2次面接結果, 退職日, 書類URL, メモ

新規取込時の出力値:
- ステータス → **「未対応」固定**
- 媒体名 → 選択された媒体の名前(JOBこあ/Indeed/engage/AirWORK/求人ボックス/その他)
- 応募日 → 画面入力 or 各行の応募日

## バックアップ

別PCへの移行や、誤削除からの復元用。
